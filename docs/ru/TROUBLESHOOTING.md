# Устранение проблем

[English](../en/TROUBLESHOOTING.md) · **Русский**

Начните с последнего запуска Actions → Commando Activity. Откройте первый упавший шаг: последующие пропущенные шаги — следствие ошибки. Не публикуйте токены и логи без проверки.

| Симптом                          | Что проверить                                                                                                                                      |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Workflow отсутствует в Actions   | Файл `.github/workflows/commando.yml` находится в основной ветке; Actions разрешены                                                                |
| Workflow/ref not found           | Релиз существует; разрешены внешние reusable workflows                                                                                             |
| Job skipped                      | Запускайте из основной ветки профильного репозитория                                                                                               |
| 401 / токен истёк                | Имя секрета, значение и срок PAT; меняйте секрет, а не YAML                                                                                        |
| Неверный владелец/scope          | Classic PAT владельца с минимальным read:user; repo и workflow не нужны                                                                            |
| Первая картинка возвращает 404   | Дождитесь успешного запуска, проверьте output и точный URL                                                                                         |
| После успеха старая картинка     | Откройте raw-картинку и обновите профиль; кеш GitHub/браузера может задержаться                                                                    |
| Output changed during generation | Повторите: результат изменился параллельной публикацией                                                                                            |
| Checksum mismatch                | Восстановите SVG и JSON вместе из одного корректного коммита output, затем повторите запуск                                                        |
| Расписание остановилось          | Проверьте Actions, срок PAT и отключение GitHub расписаний в неактивных репозиториях                                                               |
| Подтормаживает на телефоне       | Сравните raw-картинку и профиль в одном браузере; укажите устройство/iOS/браузер, локацию и релиз. Не снижайте качество до воспроизведения причины |

Для помощи создайте [сообщение об ошибке](https://github.com/0w1Max/commando-activity/issues/new?template=bug_report_ru.yml): версия, упавший шаг, браузер/устройство, ожидаемый и фактический результат. Для чувствительных проблем используйте [сообщение о безопасности](../../SECURITY.ru.md). Настройки репозитория и политики организации иногда требуют действий владельца.
