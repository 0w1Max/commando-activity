# Установка

[English](../en/INSTALL.md) · **Русский** · [Главная](../../README.ru.md)

**[Открыть помощник установки](https://0w1max.github.io/commando-activity/?lang=ru)**

Помощник подготовит ссылки; ниже объяснено каждое действие. Никогда не вводите токен в помощник.

Нужны личный аккаунт GitHub и публичный профильный репозиторий `YOUR_LOGIN/YOUR_LOGIN` с README. Форк игры не нужен. Существующее портфолио не перезаписывается.

Картинка публичная и может включать суммарные приватные вклады, доступные токену владельца. Названия репозиториев и детали коммитов не запрашиваются. Не включайте live-публикацию, если эти количества не должны быть публичными.

## 1. Добавить секрет календаря

В настройках аккаунта: Developer settings → Personal access tokens → Tokens (classic). Создайте **classic PAT** только со scope **read:user** и сроком действия. Сразу вставьте токен в профильном репозитории: Settings → Secrets and variables → Actions → New repository secret.

Имя секрета: **COMMANDO_READ_USER_TOKEN**. Не вставляйте значение в workflow, README, Issue, URL или помощник установки. Токен должен принадлежать владельцу профиля. Scope `repo`, `workflow` и административные права не нужны. Автоматический `GITHUB_TOKEN` отдельно записывает изображение в ваш репозиторий; PAT только читает календарь.

## 2. Добавить workflow

Скопируйте [examples/profile-workflow.yml](../../examples/profile-workflow.yml) в `.github/workflows/commando.yml` профильного репозитория, в default branch. Подключённый workflow загружает закреплённую версию генератора из этого проекта и публикует только в репозиторий, который его вызвал. Исходники игры в профиль не копируются.

Включите Actions, если GitHub предлагает это сделать. Нужны права `contents: write` с учётом политики репозитория. Не включайте write-токены для pull requests из форков. Actions → Commando Activity → Run workflow. Дождитесь успешного завершения.

Первый успешный запуск создаст `output` с файлами `commando-activity.svg` и `commando-state.json`. Они обновляются атомарно. Состояние нужно сохранять; готовые файлы не редактируйте вручную.

## 3. Вставить картинку

```markdown
![Commando Activity](https://raw.githubusercontent.com/YOUR_LOGIN/YOUR_LOGIN/output/commando-activity.svg)
```

Замените оба `YOUR_LOGIN`. Сначала откройте URL картинки, затем профиль. Возможен кеш. Это не непрерывная синхронизация: пример запрашивает два обновления в сутки, около 00:17 и 12:17 Москвы; GitHub может задерживать расписание.

## Неполадки и обновление

| Проблема                | Проверка                                                                                                         |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Workflow not found      | Ссылка на существующий релиз, разрешённые Actions, публичный исходный репозиторий                                |
| Job skipped             | Запуск из default branch                                                                                         |
| Нет токена / 401        | Имя секрета, значение и срок PAT                                                                                 |
| Неверный владелец/scope | Ваш classic PAT с read:user                                                                                      |
| Output changed          | Повторите: другая публикация обновила output                                                                     |
| Checksum mismatch       | Восстановите SVG и JSON вместе из последнего корректного коммита output                                          |
| Картинка 404            | Первый запуск прошёл, репозиторий публичный, URL точный                                                          |
| Нет расписания          | Actions и schedule включены, PAT действует; GitHub может отключить расписание в неактивном публичном репозитории |

Для обновления изучите новый релиз и замените версию в коротком workflow. Релизный процесс не перемещает существующие теги. Для отключения удалите workflow подключения и картинку README; историю output можно оставить. Поддержка проверена для личных аккаунтов и classic PAT. Организационные профили и fine-grained PAT требуют отдельной проверки.

Владелец подтвердил создание графики с нуля; её отдельная публичная лицензия пока не выбрана. См. [условия ресурсов](../../ASSET_RIGHTS.ru.md).
