# Происхождение и лицензия графики

[English](../en/ARTWORK.md) · **Русский**

## Состояние на 27 ноября 2026 года

Владелец подтвердил создание графики с нуля совместно с помощником и разрешил её использование по CC0 1.0. [LICENSE-ASSETS](../../LICENSE-ASSETS) определяет область; [стандартный текст CC0](../../LICENSES/CC0-1.0.txt) не изменён. Код остаётся под [MIT](../../LICENSE-CODE). Указание авторства графики необязательно; коммерческое использование разрешено в пределах CC0.

В [реестре](../../compliance/artwork-manifest.json) 19 атласов: 11 исходных и 8 оптимизированных. Их статус `owner-licensed` означает разрешение владельца, а не независимую юридическую проверку. Записаны семь архивных PNG и два компилятора с неизменяемыми ссылками, Git blob ID и SHA-256.

Четыре атласа местности — завод, каньон, храм и побережье — были побайтно воспроизведены из архивных PNG историческими Python/Pillow-компиляторами. Все восемь оптимизированных атласов воспроизводятся текущим векторным компилятором. Для фона каньона найден исходный PNG; полная процедура его преобразования не воспроизведена. Для персонажа и остальных атласов сохранены исторические байты, но полные записи первичной генерации не восстановлены. Сервис, модель и параметры генерации не выдумываются.

[Архив источников](https://github.com/0w1Max/0w1Max/tree/bf8f10350b0c82fa2e651b318b8b83298d821a36) не дублируется в runtime продукта. Архивные шрифты и сторонние материалы не входят в CC0; имена пользователей и календарь также исключены.

## Новая графика

1. Запишите источник, дату, исходные материалы и изменения; для генерации — сервис и доступные параметры.
2. Получите явное разрешение и сохраните применимые условия. Для оригинальных вкладов согласуйте CC0; чужие материалы не перелицензируйте автоматически.
3. Обновите реестр, контрольные суммы и цепочку производных файлов. Лицензия производных должна учитывать исходники.
4. Проверьте неизменность внешнего вида и мобильной отрисовки перед публикацией.

## Проверки

- `npm run check:assets:licensed` — обязательная CI-проверка: охват, хеши файлов и лицензии, заявление владельца, ссылки на разрешение и лицензии исходников. Сейчас проходит для всех 19 атласов.
- `npm run check:assets` — проверка реестра с предупреждением при незавершённых записях.
- `npm run check:assets:cleared` — совместимое старое имя строгой проверки; не означает независимую юридическую сертификацию.
- `npm run check:art` — воспроизведение восьми оптимизированных атласов.

Автоматические проверки подтверждают согласованность записей, а не подлинность разрешения или наличие авторского права. CC0 применяется только к правам, которые владелец может предоставить; она не создаёт отсутствующие права и не снимает права третьих лиц.
