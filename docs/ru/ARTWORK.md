Воспроизведение из PNG проверено через Python/Pillow во время ревью; исторический компилятор не добавляется в зависимости работающей игры.

Имена файлов, папка сгенерированных изображений и комментарии компилятора **не доказывают**, каким сервисом созданы изображения, какие референсы использованы и какие права действуют. Неизвестные поля автора, генератора и лицензии оставлены пустыми. Здесь нет вывода о краже изображений и нет заявления о подтверждении всех прав.

## Как закрыть вопрос по каждому исходнику

1. Найти первоначальную запись о создании или скачивании. Для генерации — сервис, дату, исходные изображения/референсы и ручную обработку; для скачивания — точную страницу и версию лицензии.
2. Сохранить доступное для проверки подтверждение разрешения и применимые условия. Проверить возможность распространять исходные ресурсы и полученные SVG, а не только использовать картинку внутри игры.
3. Сохранить обязательные сведения об авторстве и изменениях. Общая благодарность не заменяет требования лицензии.
4. После изучения подтверждений обновить реестр; сначала проверить исходники, затем производные.
5. Если разрешение установить не получится — заменить конкретный материал на подходящую собственную или лицензированную графику. Перед публикацией сравнить внешний вид и работу на телефоне.

Для новых сторонних материалов предпочтительны понятные CC0 или CC BY 4.0. Это критерий выбора, а не лицензия, задним числом назначенная текущей графике. Для самостоятельно созданных материалов также нужны явные условия использования. Права по договору с генератором и охраноспособность результата ИИ — разные вопросы, зависящие от страны; одного названия генератора недостаточно.

## Автоматические проверки

- `npm run check:assets` проверяет полноту, контрольные суммы, ссылки на подтверждения и согласованность производных. Сейчас проходит с явным предупреждением о неподтверждённых правах.
- `npm run check:assets:cleared` дополнительно требует проверки всех записей. **Сейчас намеренно завершается ошибкой**, поскольку проверка прав не закончена.
- `npm run check:art` воспроизводит восемь оптимизированных векторных атласов из включённых исходников.
- Реестр и REUSE/SPDX не доказывают подлинность или юридическую достаточность разрешения. Изучение подтверждений остаётся необходимым.

MIT относится к оригинальному коду в области [LICENSE-CODE](../../LICENSE-CODE). [LICENSES/MIT.txt](../../LICENSES/MIT.txt) содержит стандартный текст лицензии и не расширяет её на графику. Другие лицензии добавляются после установления их применимости. HUD использует системный monospace без вложенного файла шрифта; старые эксперименты со шрифтами OFL находятся вне текущего дерева продукта.

Превью, SVG профиля и скриншоты релиза наследуют статус включённой графики. Исключение спорного файла из следующего релиза не удалит его из старых релизов или Git-истории; подтверждённое нарушение потребует отдельного решения.
