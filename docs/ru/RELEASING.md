# Выпуск версий

[English](../en/RELEASING.md) · **Русский**

## Правила версий

Пользовательские контракты: reusable workflow, документированный CLI, имена выходных файлов/схема state и согласованное поведение анимации. Внутренние пути модулей не являются опубликованным API библиотеки.

- PATCH: совместимые исправления, усиление проверок и рефакторинг с сохранением визуального контракта.
- MINOR: новая совместимая возможность для пользователя.
- MAJOR: несовместимые изменения workflow, конфигурации, состояния или установки; нужна инструкция миграции.

2.8.2 — patch-релиз: улучшаются структура, проверки входных данных/релизов и документация, а анимация 2.8.1 остаётся эталоном.

## Порядок выпуска

1. Согласуйте package.json, настройки, каталог релиза, помощник, ссылки workflow и пример. `npm run check` блокирует расхождения.
2. Напишите соответствующие записи changelog на русском и английском: Добавлено/Изменено/Исправлено/Безопасность/Удалено по необходимости. Объясняйте влияние на пользователя, не выгружайте список коммитов и не выдумывайте изменения.
3. Выполните проверки с закреплёнными инструментами, тесты, демо и браузерное сравнение. При изменении графики проверьте права на ресурсы.
4. Объедините проверенный PR. CI основной ветки повторит обязательные проверки, затем создаст новый тег и двуязычное описание релиза. Старые теги и релизы не перезаписываются.
5. Проверьте SHA тега и успешность публикации до объявления релиза готовым. Пользователи явно обновляют ссылку в своём workflow.

GitHub Releases хранит выпуски. `commando-release.json` содержит текущие метаданные и историческое происхождение графики; это не SHA релизного тега. Для отката выберите рабочий релиз и восстановите согласованную пару SVG/state через проверенную публикацию. Автоматический откат не обещается.

2.8.3 добавляет проверки происхождения и инструкцию защиты без изменения отрисовки. Подтверждение прав и включение административных настроек остаются отдельными критериями; релизный тег их не подтверждает.

Версия 2.8.4 — patch-релиз лицензии графики и документации. Код остаётся MIT, оригинальная графика — CC0 1.0; изображения, движение и мобильная оптимизация сохранены.
