# Разработка и сопровождение

[English](../en/DEVELOPMENT.md)

Node.js 22+. `npm test` запускает регрессионные тесты; `npm run demo` создаёт явно маркированную тестовую анимацию в `generated/`. Установка npm и внешние runtime-зависимости не нужны. Анимацию проверяйте в браузере, не только по PNG.

| Модуль | Ответственность |
|---|---|
| scripts/mission.mjs | Seeded-карта, движение, прыжки, прицеливание и шкала попаданий |
| scripts/generate.mjs | GraphQL, проверка владельца/scope, календарь, сборка SVG |
| scripts/*-scene.mjs, *-sprites.mjs | Фоны и локальные runtime-атласы |
| scripts/level-art.mjs | Платформы, препятствия, тени |
| scripts/profile-hud.mjs, hud-font.mjs | Общий шрифт и интервалы месяцев |
| scripts/daily-location.mjs | Ротация по датам, запрет повторов |
| scripts/publish-daily.mjs | Генерация публикации |
| scripts/output-store.mjs | Первый output, checksum, защита от гонок, атомарные коммиты |
| scripts/validate-daily.mjs | Проверка production-результата |
| .github/workflows/generate.yml | Переиспользуемый издатель; цель определяется контекстом вызывающего профиля |
| .github/workflows/ci.yml | Проверки и релизы |

## Инварианты

Официальные сцены: desert, industrial, temple, coast. Экспериментальные миры тестируются, но не участвуют в daily-публикации. В commando-settings.json закреплены seeds и цикл Europe/Moscow. Не меняйте seed уже опубликованной сегодня сцены без отдельной миграции состояния. Повторный запуск в тот же день сохраняет локацию; пропуски дней не должны давать повтор подряд.

Общий кадр 1200×469, viewBox `0 -32 1200 469`, клетки 18 px с шагом 20, начало поля (72,60). Ник monospace bold 21 px, базовая линия -8. Месяцы monospace bold 15 px, базовая линия 46. Палитры различаются; геометрия, метрики и координаты едины. Отдельного увеличения побережья нет. Коллизии должны совпадать с графикой и реальными ключевыми кадрами прыжков; пули стартуют из дула и попадают в нужную клетку.

## Ветки и релизы

main — рабочая версия. На каждое изменение создаётся короткоживущая ветка: PR → тесты → merge → удаление завершённой ветки. Ветка — полный снимок репозитория, а не папка. Не используйте ветки как постоянное меню версий локаций. Стабильные версии хранятся тегами и релизами; архив экспериментов не включается в основное дерево.

Перед релизом согласуйте версии package/settings/catalog и закреплённые refs в generate.yml и примере подключения. Проверьте демо и все четыре сцены. После тестов CI создаёт тег; существующие теги не перемещаются. Пользователи обновляются явно. Защиту main и обязательный CI настройте в GitHub, если это допускает политика аккаунта; наличие такой защиты здесь не утверждается.

Секреты остаются в вызывающем профильном репозитории. Не копируйте и не извлекайте PAT в проект игры. Публикация без force: SVG и состояние одним коммитом. Ошибка API сохраняет прежнее изображение. Автоматического отката нет: восстанавливайте согласованную пару SVG/state новым коммитом либо возвращайте версию подключения с проверенной миграцией.

Исторические календари в fixtures нужны только тестам. Художественные компиляторы, отвергнутые шрифты и тяжёлые визуальные эксперименты остаются в архиве v2.7.0 исходного репозитория, а не среди runtime-файлов.

## Оптимизация отрисовки (2.8.1)

`node scripts/compile-pixel-art.mjs` пересобирает атласы `*-optimized.json.gz.b64` из оригиналов `*-sprites.json.gz.b64`. Флаг `--check` проверяет соответствие исходникам. Соседние пиксельные прямоугольники одного цвета объединяются в точные векторные контуры. Цвета, отверстия, координаты и исходная графика сохраняются; простые непрямоугольные пути не меняются. Растеризации и внешних runtime-зависимостей нет.

`shot-pool.mjs` повторно использует эффекты после исчезновения предыдущих вспышки, пули и попадания. Перекрывающиеся эффекты получают отдельные элементы. Меняется представление SVG, а не планировщик, тайминги выстрелов, кадры бойца, траектории, календарь или ротация. Сравнивайте одинаковые календари/seeds при настольной и мобильной ширине; эмуляция браузера не подтверждает FPS на iPhone.

CI сравнивает четыре локации с тегом v2.8.0 в Chromium и WebKit при 1200px/1× и 390px/3×: полёт пули, попадание, прыжок и восстановление. Инструменты QA устанавливаются отдельно и не нужны пользователям. Сравнение воспроизводится через `tools/verify-rendering.cjs` с отдельной эталонной копией репозитория.
