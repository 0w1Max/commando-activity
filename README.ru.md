# Commando Activity

[English](README.md) · **Русский**

Ваш календарь активности GitHub — в виде живого пиксельного мира.

[![Проверки](https://github.com/0w1Max/commando-activity/actions/workflows/ci.yml/badge.svg)](https://github.com/0w1Max/commando-activity/actions/workflows/ci.yml)

![Живая анимация](https://raw.githubusercontent.com/0w1Max/0w1Max/output/commando-activity.svg?v=2.8.3)

Четыре сменяющие друг друга локации. Боец патрулирует уровень, перепрыгивает препятствия и расстреливает клетки вашего календаря. Это SVG-анимация по реальной активности, без управления клавиатурой и собственного сервера.

**Текущая версия: 2.8.3.** Оптимизация для телефонов из 2.8.1 сохранена.

## Добавить в профиль

**[Открыть помощник установки →](https://0w1max.github.io/commando-activity/?lang=ru)**

Введите логин GitHub. Помощник подготовит workflow и строку для README прямо в браузере. Вводить токен в помощник не нужно.

1. Добавьте собственный classic PAT с минимальным scope **read:user** в секрет профильного репозитория **COMMANDO_READ_USER_TOKEN**.
2. Добавьте подготовленный workflow, запустите его во вкладке Actions и дождитесь успешной публикации.
3. Вставьте подготовленную строку картинки в README.

Форк, установка npm и копирование исходников игры в профиль не нужны. Существующее портфолио остаётся на месте. Потребуются права записи в ваш публичный репозиторий `LOGIN/LOGIN` и разрешённый запуск GitHub Actions.

**Права на графику:** оригинальный код распространяется по [MIT](LICENSE-CODE). Владелец подтвердил создание графики с нуля совместно с помощником; её отдельная публичная лицензия пока не выбрана, и MIT на код её не охватывает. Перед её распространением или переработкой прочитайте [условия ресурсов](ASSET_RIGHTS.ru.md).

## Как это работает

GitHub Actions получает календарь, строит воспроизводимую миссию, формирует автономный SVG и одним коммитом сохраняет картинку и состояние в ветке `output` вашего профиля. Пример запускается дважды в сутки; расписание GitHub и кеш изображений могут задерживать обновления.

В профиле хранятся небольшой workflow с закреплённой версией и готовый результат. Исходники остаются здесь. Обновление выполняется явно: изучите релиз и замените ссылку `@v…` в workflow. Существующие релизные теги не перемещаются.

| Каталог                   | Назначение                                                    |
| ------------------------- | ------------------------------------------------------------- |
| `src/domain/`             | Чистые вычисления: карта, движение, прицеливание, выбор целей |
| `src/calendar/`           | Проверка календаря и обращения к GitHub                       |
| `src/art/`, `src/render/` | Пиксельная графика и сборка SVG                               |
| `src/publication/`        | Ротация, проверка и атомарное сохранение результата           |
| `scripts/`                | Небольшие точки входа командной строки                        |
| `site/`                   | Помощник установки на русском и английском                    |
| `tests/`, `tools/`        | Тесты и проверки репозитория                                  |
