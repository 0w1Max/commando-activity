# Участие в проекте

[English](CONTRIBUTING.md) · **Русский**

Начните с [руководства разработчика](docs/ru/DEVELOPMENT.md) и [архитектуры](docs/ru/ARCHITECTURE.md). Для изменения поведения сначала создайте предметный Issue; небольшие исправления можно сразу предложить через PR.

Одна короткоживущая ветка — одна задача. Опишите проблему, итоговое поведение и проверки. Сохраняйте порядок RNG, координаты и согласованность выходных файлов. Добавляйте регрессионный тест реального дефекта, а не копию реализации. Не коммитьте секреты и готовую live-публикацию в исходники.

Перед проверкой: `npm ci`, `npm run check`, `npm run lint`, `npm run format:check`, `npm test`, `npm run demo`. CI дополнительно сравнит Chromium/WebKit. Для новой графики нужны источник и разрешение: [условия ресурсов](ASSET_RIGHTS.ru.md). Проблемы безопасности сообщайте [приватно](SECURITY.ru.md).

Проект — небольшой генератор на функциях. Предпочитайте понятные границы универсальным фреймворкам и слоям без задачи. Комментарии должны объяснять неочевидные инварианты; рекламные заявления и устаревшие заметки экспериментов не нужны. Русская и английская документация описывают одинаковое поведение и переключаются на соответствующую страницу.
